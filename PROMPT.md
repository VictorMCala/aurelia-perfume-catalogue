- Emotion

- Desire

- Experience

Never sound like ecommerce copy.

# AUTOMATIC REJECTION RULES

Reject and redesign immediately if any page includes:

- Pure white bottle cut-outs
- E-commerce style layouts
- Generic catalogue grids
- Repeating page structures
- Stock image appearance
- Weak typography
- Low visual drama
- Empty white space with no purpose
- Product-page monotony
- Ordinary retail presentation
